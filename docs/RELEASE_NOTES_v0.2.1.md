# PWDog 0.2.1

修复安装版无法找到浏览器扩展文件夹的问题。

## 修复内容

- 扩展文件现在随应用一起打包，安装后不再依赖源码目录。
- “设置 → 浏览器自动填充”新增“打开扩展文件夹”：
  - 自动把扩展解压到 `%LOCALAPPDATA%\PWDogData\extension`；
  - 在资源管理器中打开该文件夹；
  - 可一键复制文件夹路径。
- 配对步骤文案同步更新为安装版流程。
- 新增扩展资源解压与刷新测试。
- 安装目录中没有 `uninstall.exe`；也可以从 Windows 设置 → 应用 → 已安装的应用中卸载。

## 加载扩展

1. 安装 0.2.1，打开 PWDog → 设置 → 浏览器自动填充。
2. 点击“打开扩展文件夹”。
3. 在 Chrome / Edge 扩展管理页启用开发者模式。
4. 选择“加载已解压的扩展程序”，选中打开的 `extension` 文件夹。
5. 将配对页显示的接口地址与令牌填入扩展设置。

扩展不会自动提交表单；PWDog 锁定时不会返回密码。

## 升级说明

从 0.2.0 升级会保留现有账户和密码库，不会触发数据清理。安装包未签名，SmartScreen 可能提示未知发布者。

如果旧版是以管理员权限安装的（注册在“所有用户”下），请先备份 `%LOCALAPPDATA%\PWDogData`，从 Windows 设置卸载旧版，再安装 0.2.1，并把备份目录放回原位。这样可避免机器级与用户级安装并存。
