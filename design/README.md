# Quiet Vault design reference

These HTML files document the visual direction used by the shipping application. They are **reference material only** — PWDog is a Compose Desktop app, and `desktopApp/` is the source of truth for the UI.

- `PWDog Quiet Vault v1.html` — full interactive visual reference
- `PWDog Quiet Vault v0.html` — earlier direction

Do not ship the HTML files as the product. When changing the interface, implement the change in Compose and use these files only for layout, palette, and typography reference.
